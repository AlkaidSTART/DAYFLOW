# DAYFLOW UI 设计风格规范

> 版本：V1.0
> 适用范围：DAYFLOW 移动端全部页面与组件
> 关联文档：[PRD.md](./PRD.md)、[tech-stack.md](./tech-stack.md)

---

## 1. 设计方向

### 1.1 一句话定义

**温暖、克制、有呼吸感的每日工作台。**

白天打开时不刺眼，夜晚打开时不发灰；信息以「今天」为中心，永远只突出当下最该做的一件事。

### 1.2 关键词

| 关键词   | 表现                                                         |
| -------- | ------------------------------------------------------------ |
| 暖       | 米白、陶土、纸质色调，避免纯白冷光与高饱和荧光色             |
| 静       | 大面积留白、少分割线、弱化非核心信息                         |
| 稳       | 同一个组件形态在所有页面一致，不追求炫技动画                 |
| 有反馈   | 每次完成都有轻微但明确的视觉与触觉确认                       |
| 不焦虑   | 不用红色大面积警告，不用倒计时压迫感，不用连续打卡压力       |

### 1.3 参考气质

- 纸质手账 / 便签的触感
- 晨间自然光下的木色与陶土色
- 系统原生的操作手感（Android 返回手势、原生底部导航）

### 1.4 明确避免

- 纯黑 `#000000` 背景 + 纯白 `#FFFFFF` 文字的高对比「开发者审美」
- 大面积蓝紫渐变、玻璃拟态、霓虹光效
- Emoji 作为图标或装饰
- 超过 400ms 的入场动画
- 打卡排行榜、连击火焰等制造焦虑的机制

## 2. 色彩系统

### 2.1 设计原则

- 所有正文对比度 ≥ 4.5:1（WCAG AA）。
- 色彩承担语义：陶土色 = 主要操作 / 今日重点；绿色 = 完成；琥珀 = 提醒；砖红 = 危险。
- 同一语义在浅色与深色下保持相同色彩倾向，只调整明度。
- 不使用纯黑、纯白作为大面积背景。

### 2.2 语义 Token

| Token            | 用途                     | 浅色      | 深色      |
| ---------------- | ------------------------ | --------- | --------- |
| `canvas`         | 页面背景                 | `#FAF7F2` | `#16130F` |
| `surface`        | 卡片 / 内容容器          | `#FFFFFF` | `#201C17` |
| `surface-muted`  | 次级容器 / 输入框底      | `#F2ECE4` | `#2A251E` |
| `surface-selected` | 选中态底               | `#E8DFD3` | `#342D25` |
| `line`           | 分割线 / 边框            | `#E5DCD0` | `#3A332A` |
| `ink`            | 主文字                   | `#1C1917` | `#F5F0E8` |
| `ink-muted`      | 次级文字                 | `#6B6259` | `#B3A99C` |
| `ink-subtle`     | 辅助说明 / 占位符        | `#78706A` | `#9A9083` |
| `accent`         | 主操作 / 品牌强调        | `#A8482A` | `#E89B7A` |
| `accent-soft`    | 强调色浅底               | `#F6E3D9` | `#3A241B` |
| `on-accent`      | 强调底上的文字           | `#FFFFFF` | `#1C1917` |
| `success`        | 完成 / 正向              | `#3F7A55` | `#7FB894` |
| `warning`        | 预算提醒 / 注意          | `#8A5A05` | `#D9A441` |
| `danger`         | 删除 / 中断              | `#B3261E` | `#F2867D` |

### 2.3 对比度校验

| 组合                                   | 对比度 | 结论     |
| -------------------------------------- | -----: | -------- |
| `ink` on `canvas`（浅）                | 16.0:1 | AA / AAA |
| `ink-muted` on `canvas`（浅）          |  5.6:1 | AA       |
| `ink-subtle` on `canvas`（浅）         |  4.5:1 | AA       |
| `accent` on `canvas`（浅）             |  5.4:1 | AA       |
| `on-accent` on `accent`（浅，白字）    |  5.8:1 | AA       |
| `success` on `canvas`（浅）            |  4.8:1 | AA       |
| `warning` on `canvas`（浅）            |  5.6:1 | AA       |
| `danger` on `canvas`（浅）             |  6.1:1 | AA       |
| `ink` on `canvas`（深）                | 16.6:1 | AAA      |
| `ink-muted` on `canvas`（深）          |  8.1:1 | AAA      |
| `accent` on `canvas`（深）             |  8.4:1 | AAA      |
| `on-accent` on `accent`（深，深字）    |  8.4:1 | AAA      |

> 任何新增颜色必须先过对比度检查；`ink-subtle` 仅用于 ≥ 14px 的辅助文字，不用于关键信息。

## 3. 字体与排印

### 3.1 字体选择

- **正文与界面**：系统字体（Android Roboto / iOS SF Pro）。理由：原生观感、零加载成本、中文回退自然。
- **数字（计时、金额）**：系统字体 + `fontVariant: ['tabular-nums']`，保证跳动时不抖动。
- **不引入自定义展示字体**，避免包体增大与中英文混排不一致。

### 3.2 类型层级

| 名称        | 字号 / 行高 | 字重 | 用途                                   |
| ----------- | ----------- | ---- | -------------------------------------- |
| Display     | 40 / 48     | 600  | 计时器（可放大至 64/72）、预算大金额    |
| H1          | 28 / 36     | 600  | 页面标题（今日 / 专注 / 钱包）          |
| H2          | 22 / 30     | 600  | 区块标题（今日重点、本月概览）          |
| Body        | 16 / 24     | 400  | 任务标题、账单备注、正文                |
| Body Strong | 16 / 24     | 600  | 任务标题（未完成）、按钮文字            |
| Caption     | 14 / 20     | 400  | 时间、分类、辅助说明                    |
| Micro       | 12 / 16     | 500  | 标签、单位、图表图例                    |

规则：

- 单个页面最多出现 3 个层级，避免字号过密。
- 中文不使用全大写或夸张字距；英文标签可用 `uppercase` + 0.04em 字距。
- 数字与单位之间留半角空格：`25 min`、`¥ 1,280.00`。
- 文本支持系统字体缩放，测试上限 200% 不截断关键信息。

## 4. 间距、圆角与层级

### 4.1 间距刻度

| Token | 值  | 典型用途                     |
| ----- | --- | ---------------------------- |
| 0.5   | 2   | 图标与文字间距               |
| 1     | 4   | 紧凑标签内边距               |
| 2     | 8   | 行内元素间距                 |
| 3     | 16  | 卡片内边距、列表行间距       |
| 4     | 24  | 页面左右边距（默认）         |
| 5     | 32  | 区块之间间距                 |
| 6     | 48  | 页面顶部大留白               |
| 8     | 64  | 空状态 / 专注页大留白        |

- 页面左右安全边距统一 **24**；卡片内边距统一 **16**。
- 同类元素纵向间距只用 8 的倍数。
- 列表行最小高度 56，触控目标最小 48×48。

### 4.2 圆角

| Token | 值  | 用途                     |
| ----- | --- | ------------------------ |
| sm    | 8   | 标签、输入框内部元素     |
| md    | 14  | 按钮、输入框、小卡片     |
| lg    | 20  | 内容卡片、任务行         |
| xl    | 28  | 底部弹层顶部、重点卡片   |
| full  | 999 | 圆形勾选、FAB、头像      |

### 4.3 层级表达

- **浅色**：使用 1px `line` 边框 + 极轻暖色阴影（`rgba(60, 40, 20, 0.06)`，y=2，blur=12）。
- **深色**：不使用阴影，通过 `canvas → surface → surface-muted` 的明度递进表达层级。
- 禁止重投影与多层阴影。

## 5. 图标与插画

- 只使用 **outlined** 或 **rounded** 风格图标，线宽 1.8–2。
- 默认尺寸 24，列表内 20，标签内 16。
- 图标颜色跟随文字颜色，选中态用 `accent`。
- **禁止使用 Emoji**（含分类图标、空状态、按钮）。
- 底部 Tab 图标：Today = 日历/太阳轮廓，Focus = 计时器轮廓，Wallet = 钱包轮廓；选中时使用实心变体或 `accent` 着色。
- 空状态使用简单线性插画或纯图形组合，不使用 3D 渲染图。

> 现有脚手架的 Tab 图标为 PNG 模板图，替换为统一的 outlined 图标集（`@expo/vector-icons` 已随 Expo 提供）。

## 6. 组件规范

### 6.1 底部导航

- 三个 Tab：Today / Focus / Wallet，使用原生底部导航。
- 高度遵循系统安全区；图标 24，标签 12。
- 选中态：图标与标签使用 `ink`，背景胶囊使用 `surface-selected`；未选中 `ink-muted`。
- 不使用浮动胶囊 Tab 或自定义大圆角 Tab。

### 6.2 任务行（TaskRow）

```
┌──────────────────────────────────────────────┐
│  ○   写实验报告                               │
│     学习 · 今天 14:00             [1]         │
└──────────────────────────────────────────────┘
```

| 属性       | 规格                                                       |
| ---------- | ---------------------------------------------------------- |
| 高度       | 最小 56，多行描述可自适应                                  |
| 圆角       | `lg`（20）                                                 |
| 背景       | `surface`，间距 8 分隔                                     |
| 勾选框     | 24×24 圆形，边框 2px `line`；完成时填充 `success` + 白色对勾 |
| 标题       | Body Strong；完成后 `ink-subtle` + 删除线                   |
| 副标题     | Caption，`ink-muted`，可选                                 |
| Top 3 标记 | 24×24 圆角 8 的 `accent-soft` 底 + `accent` 序号文字        |
| 左滑       | 显示删除按钮（`danger` 底），需二次确认                     |
| 长按       | 进入拖拽排序                                               |

完成动画：勾选圆圈 180ms `easeOutCubic` 缩放弹入，标题删除线 200ms 从左到右绘制；不做全屏彩带。

### 6.3 今日重点区（TopThreeSection）

- 区块标题：「今天最重要的三件事」+ 右侧「编辑」文字按钮。
- 空位展示为虚线卡片：`border-dashed border-line`，中间 `ink-subtle` 提示「添加第 N 件事」。
- 三张卡片使用相同的任务行样式，仅通过序号标记区分，不做卡片尺寸差异。
- 全部完成时区块底部出现一行 `success` 小字：「今天的重点已完成」。

### 6.4 进度卡（ProgressCard）

- 卡片内含：`已完成 2 / 5`、百分比、细进度条。
- 进度条高度 6，圆角 full，轨道 `surface-muted`，填充 `accent`。
- 无任务时：进度条隐藏，展示「今天还没有任务」+ 新建按钮，不展示 0% 或 NaN。
- 百分比文字使用 `tabular-nums`。

### 6.5 Focus 计时页

```
              ○  专注
        ┌──────────────────┐
        │      24:59       │
        │   ───────────    │
        └──────────────────┘
        关联：写实验报告
        [ 暂停 ]   [ 结束 ]
        专注 25 · 休息 5 · 长休 15
```

| 属性       | 规格                                                          |
| ---------- | ------------------------------------------------------------- |
| 模式切换   | 顶部三段式 Segmented Control，选中底 `surface-selected`       |
| 计时数字   | Display 放大版 64/72，`tabular-nums`，`ink`；暂停时 `ink-muted` |
| 进度       | 计时器下方 4px 线性进度条，`accent` 填充；MVP 不使用环形图     |
| 主按钮     | 填充 `accent`，白字，圆角 full，高 56，宽度自适应留白          |
| 次按钮     | 描边 `line`，`ink` 文字，透明底                               |
| 关联任务   | 一行可点击区域，未关联时显示「选择任务」+ `ink-muted`          |
| 休息模式   | 主色切换为 `success`，进度条同色                              |
| 完成态     | 数字替换为「完成」+ 本次时长 +「再来一次」按钮                 |

- 计时中屏幕常亮可选（设置项），默认关闭。
- 结束操作使用底部弹层二次确认：「结束本次专注并记录？」。

### 6.6 预算卡（BudgetCard）

```
本月预算
¥ 1,280.00              已用 62%
[████████████░░░░░░░]
剩余 ¥ 486.00 · 每日约 ¥ 32.40
```

- 大金额 Display 32–40，`tabular-nums`。
- 使用率 > 80%：进度条变 `warning`；超支：进度条 `danger`，并显示「已超出 ¥ 120.00」。
- 未设置预算：展示「设置本月预算」按钮，不展示进度条。
- 每日可用金额按分取整后展示两位小数。

### 6.7 账单行（BillRow）

```
┌──────────────────────────────────────────────┐
│ [图标] 食堂午饭              -¥ 18.00         │
│        餐饮 · 今天 12:30                       │
└──────────────────────────────────────────────┘
```

- 支出金额前加 `-`，使用 `ink`；收入加 `+`，使用 `success`。
- 分类图标放在 40×40 的 `surface-muted` 圆角方块中。
- 点击进入编辑；左滑删除。

### 6.8 分类选择器

- 网格布局，每行 4 个，图标 + 名称。
- 选中态：`accent-soft` 底 + `accent` 图标与文字。
- 支出 / 收入切换在顶部 Segmented Control。

### 6.9 按钮

| 类型     | 背景     | 文字        | 用途                     |
| -------- | -------- | ----------- | ------------------------ |
| Primary  | `accent` | `on-accent` | 开始专注、保存账单、确认 |
| Secondary| `surface-muted` | `ink` | 取消、次要操作        |
| Ghost    | 透明     | `accent`    | 文字按钮（编辑、查看全部）|
| Danger   | `danger` | `#FFFFFF`   | 删除确认                 |

- 高度：大按钮 56，普通 48，小按钮 36。
- 圆角：大按钮 full，其余 `md`。
- 按压态：缩放 0.97 + 透明度 0.9，100ms。
- 禁用：透明度 0.4，不改变颜色。

### 6.10 输入框

- 默认：`surface-muted` 底，无边框，圆角 `md`，高 48。
- 聚焦：1px `accent` 边框 + `accent-soft` 外发光（只在 Web/浅色使用，原生用边框即可）。
- 金额输入：数字键盘，右对齐，`tabular-nums`，前置 `¥` 固定。
- 错误态：`danger` 边框 + 下方 Caption 说明。

### 6.11 底部弹层（Sheet）

- 顶部圆角 `xl`，背景 `surface`，拖拽指示条 36×4 `line`。
- 遮罩 `rgba(28, 25, 23, 0.35)`。
- 最大高度 85%，内容超出可滚动。
- 用于：新建/编辑任务、记一笔、结束确认、预算设置。

### 6.12 提示与空状态

- 页面内提示条：`accent-soft` 或 `warning/10` 底，左侧图标，右侧可关闭；不使用长驻横幅。
- 操作成功：底部 Snackbar，2 秒自动消失，可撤销。
- 空状态：线性图形 + 一句话说明 + 一个主按钮，文案见第 11 节。

## 7. 页面布局

### 7.1 Today

```
安全区
 今天 · 11月3日 星期一                    [设置]
 早上好，今天想完成什么？

 今天最重要的三件事                       [编辑]
 ┌────────────────────────────────────────┐
 │ ① 写实验报告                    ○      │
 ├────────────────────────────────────────┤
 │ ② 复习线性代数                  ○      │
 ├────────────────────────────────────────┤
 │ ③ 跑步 3 公里                   ○      │
 └────────────────────────────────────────┘

 今日进度
 ┌────────────────────────────────────────┐
 │ 已完成 1 / 4            25%            │
 │ ██████░░░░░░░░░░░░░░░░░                │
 │ 专注 1 次 · 共 25 分钟      查看专注 →  │
 └────────────────────────────────────────┘

 其他任务
 ○ 取快递
 ○ 回复导师邮件
                        (+) 添加任务

                              [FAB 记录一笔? 否，仅 Wallet]
```

- 页面上下结构：问候 → Top 3 → 进度与专注摘要 → 其他任务。
- 设置入口放在右上角，使用齿轮 outline 图标。
- 添加任务使用列表底部的虚线行，不使用悬浮按钮（避免遮挡）。

### 7.2 Focus

- 无滚动，竖向居中布局。
- 顶部：模式切换；中部：计时；下部：关联任务 + 控制按钮；底部：今日统计一行。
- 休息模式下整体主色由 `accent` 切换为 `success`，但背景不变。

## 8. 动效规范

### 8.1 总则

- 单次动画时长上限 **400ms**。
- 统一使用物理缓动：`Curves.easeOutCubic` 等价 `cubic-bezier(0.33, 1, 0.68, 1)`；退出使用 `easeOut`。
- 动画只表达因果与层级，不做装饰性循环动画。
- 使用 Reanimated 在 UI 线程执行，避免 JS 卡顿。
- 尊重系统「减少动态效果」设置。

### 8.2 动效清单

| 场景             | 时长 | 曲线          | 描述                                   |
| ---------------- | ---: | ------------- | -------------------------------------- |
| 按钮按压         | 100ms | easeOut      | scale 1 → 0.97，松开回弹               |
| 任务勾选         | 180ms | easeOutCubic | 圆圈缩放 0.8 → 1，背景色渐变至 `success` |
| 删除线           | 200ms | easeOutCubic | 宽度 0 → 100%                          |
| 进度条数值变化   | 300ms | easeOutCubic | 宽度/颜色过渡                          |
| 卡片进入         | 240ms | easeOutCubic | opacity 0 → 1，translateY 12 → 0       |
| 底部弹层         | 280ms | cubic-bezier(0.32, 0.72, 0, 1) | translateY 100% → 0 |
| 遮罩             | 200ms | easeOut       | opacity 0 → 0.35                       |
| 页面切换         | 系统默认 | —          | 使用原生 Stack 转场                    |
| 完成提示         | 320ms | easeOutCubic | 轻微 scale 1 → 1.02 → 1 + 淡入         |

### 8.3 禁用场景

- 不做持续脉动、呼吸光晕、粒子特效。
- 不做列表项依次错峰入场（长列表会拖慢首屏感知）。
- 不做数字滚动里程表的长时间动画，计时数字直接切换。

## 9. 触觉反馈

| 场景                 | 强度 / 类型                        |
| -------------------- | ---------------------------------- |
| 开始专注             | Light Impact                       |
| 暂停 / 继续          | Light Impact                       |
| 完成专注             | Success Notification               |
| 完成任务             | Light Impact                       |
| 删除 / 超支等确认    | Warning Notification               |
| 切换 Tab             | 无                                 |
| 滚动 / 普通点击      | 无                                 |

- 提供全局开关，默认开启。
- 开关关闭后所有业务触觉调用直接返回，不做退化为动画。

## 10. 无障碍

- 正文对比度 ≥ 4.5:1，大字号 ≥ 3:1。
- 触控目标 ≥ 48×48 dp，视觉尺寸可小于触控区域。
- 所有图标按钮必须有 `accessibilityLabel`；纯装饰元素设置 `accessible={false}`。
- 不依赖颜色单独传达状态：完成 = 勾选 + 删除线；超支 = 文字 + 图标 + 颜色。
- 支持系统字体缩放 200%：卡片高度自适应，禁止固定高度裁切文字。
- 支持屏幕阅读器顺序：标题 → 内容 → 操作。
- 动画遵循「减少动态效果」，开启时直接切换终态。
- 输入框错误提示与字段建立语义关联，不能只靠红框。

## 11. 文案语气

- 第二人称、简短、具体，不卖萌、不喊口号。
- 成功：陈述事实（「已记录」「专注完成」），不夸奖。
- 失败：说明原因 + 下一步（「备份文件版本过高，请先升级应用」）。
- 空状态：
  - Today：「今天还没有任务，从最重要的一件事开始。」
  - Focus：「还没有专注记录，开始第一个 25 分钟。」
  - Wallet：「本月还没有账单，记下第一笔支出。」
- 危险操作：说明后果，不用感叹号（「将删除这条账单，且无法恢复」）。
- 金额一律保留两位小数并带 `¥`；时长使用「25 分钟」，不写「25min」。

---

## 12. 暗色模式

- 背景使用暖黑 `#16130F`，不使用纯黑。
- 卡片通过 `surface` 提亮，不使用阴影。
- 强调色提亮为 `#E89B7A`，保证深底可读。
- 图表色同步使用对应深色变体，保持相同分类色相。
- 图片与图标使用 `template` 渲染，颜色随 `ink` 切换。
- 切换方式：设置项三选一，跟随系统时监听 `Appearance` 变化；切换即时生效，无需重启页面。

## 13. Do / Don't

| Do                                      | Don't                                    |
| --------------------------------------- | ---------------------------------------- |
| 用留白和层级区分信息                    | 用大量分割线和边框堆砌结构               |
| 每个页面只有一个主操作                  | 同一屏出现两个同权重填充按钮             |
| 金额、时间使用等宽数字                  | 数字跳动时宽度抖动                       |
| 完成反馈轻量、即时                      | 全屏动画、彩带、连续震动                 |
| 空状态给出明确入口                      | 空白页 + 「暂无数据」                    |
| 图标线性、统一尺寸                      | 混用填充 / 线性 / 彩色图标               |
| 超支用提示条 + 文字说明                 | 满屏红色警告、羞辱性文案                 |
| 动画 ≤ 400ms、物理缓动                  | 弹跳、旋转、无限循环动效                 |
